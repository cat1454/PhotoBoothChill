# Working Rules

Updated: 2026-04-04

## 1. Muc Dich

File nay ghi lai quy uoc lam viec giua user va Codex trong repo nay.

## 2. Quy Uoc Bat Buoc

- Truoc khi xu ly bat ky yeu cau moi nao, phai doc cac file `.md` lien quan trong repo.
- Uu tien doc it nhat:
  - `project_overview.md`
  - `roadmap.md`
  - `api-spec.md`
  - `database-design.md`
  - `implementation-status.md`
- Neu task lien quan den mot file `.md` cu the, phai doc chinh file do truoc khi lam.
- Sau khi hoan thanh moi cong viec, phai cap nhat lai tai lieu `.md` phu hop de trang thai tai lieu khop voi code va quyet dinh moi.

## 3. Nguyen Tac Cap Nhat Tai Lieu

- Neu thay doi lien quan den tien do hoac pham vi da lam, cap nhat `implementation-status.md`.
- Neu thay doi lien quan den dinh huong tong quan san pham, cap nhat `project_overview.md`.
- Neu thay doi lien quan den milestone, uu tien, hoac plan tiep theo, cap nhat `roadmap.md`.
- Neu thay doi lien quan den API, cap nhat `api-spec.md`.
- Neu thay doi lien quan den schema, migration, asset model, hoac storage key, cap nhat `database-design.md`.
- Neu thay doi la quy uoc lam viec giua user va Codex, cap nhat chinh file `working-rules.md`.

## 4. Cach Lam Viec Mac Dinh

- Khong coi tai lieu la phan phu; tai lieu phai duoc cap nhat cung voi code.
- Neu co xung dot giua code va tai lieu, uu tien sua de hai ben dong bo lai.
- Moi task hoan thanh can de lai dau vet tai lieu de lan sau co the tiep tuc nhanh.
